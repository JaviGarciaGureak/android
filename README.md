# Navegador a pantalla completa

- La primera vez que se abre, la app pide la URL y la guarda.
- Para cambiarla: toca la pantalla, aparece un botón ⚙ arriba a la derecha; al pulsarlo
  puedes editar la URL, guardarla o recargar la página.

## Compilar
1. Abre la carpeta en Android Studio y pulsa Build > Build APK(s).
   El APK queda en `app/build/outputs/apk/debug/app-debug.apk`.
2. Copia el APK al móvil e instálalo (permite "instalar apps de orígenes desconocidos").

Alternativa: sube el proyecto a GitHub; la pestaña Actions compila el APK.
